# Your First Python Contribution

A free video course that takes you from "I've never opened a pull request"
to a merged contribution to a real Python project.

- **Lesson 02 needs no install.** You open your first pull request in the
  browser. A bot checks it and merges it within a minute.
- **Then the real tools:** git, GitHub CLI, virtualenvs, pytest, ruff,
  pre-commit — the things maintainers will actually check.
- **Then a real project:** finding an issue nobody else is working on,
  reporting a bug so it gets fixed (with a practice program full of bugs),
  writing a pull request that's easy to review,
  passing CI, handling review, and using AI tools without annoying maintainers.
- **You finish with a merged PR in a project you chose**, verified by a bot
  and added to the graduates wall. After that you can contribute anywhere.

**You do every step by hand, in the terminal. No AI agent does it for you.**
That's on purpose, even though an agent can open a pull request in minutes:
your name is on it, so you have to check what the agent did, explain every
line, fix things when git goes wrong, and talk to maintainers yourself.
[Lesson 01](lessons/01-what-counts/) has the four reasons.

👉 Start with [the curriculum](CURRICULUM.md).

The hands-on exercises happen right here: in Lesson 02 you star and fork
this repo, then add your own file to [`first-commits/`](first-commits/) as
your first commit. A bot checks it and, when it's right, merges it.

## How this course is made

Lessons and video scripts are drafted with AI and **reviewed by a human
before anything is published**. Commands shown in lessons are run in CI
(`tools/test_commands.py`); the few that need your own account, like logging
in, are marked and explained. Videos are generated from the scripts in this repo
(`tools/render_video.py`), so fixing a mistake means fixing a text file and
re-rendering. If you spot something wrong, please
[open an issue](https://github.com/thejesh23/first-python-contribution/issues) — that's a contribution too.

## Repo layout

```
lessons/NN-slug/   README.md, script.md, exercise.md, quiz.md
first-commits/     one file per learner, added in Lesson 02
practice/          Exercise 2 and the planted slugify bug (Lessons 05 and 10)
bug-hunt/          splitbill, a small program with bugs to report (Lesson 09)
tools/             lesson checker, video renderer (Python)
tests/             tests for the tools and lesson structure
publishing/        Udemy landing page copy (tools/udemy_package.py builds dist/udemy/)
```

## Working on the course

```bash
uv run pytest           # check lesson structure and tools
uv run ruff check .     # lint
uv run python tools/render_video.py lessons/01-what-counts   # render a video
```

Videos are narrated by an Azure AI Speech voice, and every clip is checked by
transcribing it back (`tools/azure_tts.py` says how to set up a key). Without
a key, add `--voice Aman` to narrate with a macOS voice instead.
